# Sin Calculator — вариант 13

Java Swing desktop application for laboratory work, variant 13.

## Features
- MVC architecture with an active model (listeners).
- Separate input dialog.
- Name field and persistent last entered data using Java Preferences.
- Automatic date formatting: `10092000` -> `10.09.2000`.
- Input validation.
- Result is 0 when all sin-related answers are 0.
- Dark neon pink design with a horned kitten image.
- If the result is greater than 1000, the bundled confession audio starts asynchronously.

## Run
Open the project in IntelliJ IDEA, use JDK 17, and run `Main.java`.
